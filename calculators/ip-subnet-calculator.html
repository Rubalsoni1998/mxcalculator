IP Subnetting

A subnet (subnetwork) is a logical subdivision of an IP network. The practice of dividing a network into two or more networks is called subnetting.

CIDR

Classless Inter-Domain Routing (CIDR) is a method for allocating IP addresses and IP routing. It replaces the previous classful network architecture (Class A, B, C).
