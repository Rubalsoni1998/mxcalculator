About Percentages

A percentage is a number or ratio expressed as a fraction of 100. It is often denoted using the percent sign, "%".

Common Formulas

  • Percentage of a number: P% * X = Y
  • Find the percentage: Y / X * 100 = P%
  • Percentage Change: (New Value - Old Value) / |Old Value| * 100

Percentage Change

Percentage change shows the difference between an old value and a new value as a percentage of the old value. A positive result indicates an increase, while a negative result indicates a decrease.
