Pace Calculation

This calculator determines the pace for a given distance and time. It can also calculate the time taken to run a specific distance at a certain pace, or the distance run for a given time and pace.

Using the Calculator

  • Calculate Pace: Enter distance and time. Useful for finding out how fast you ran a recent race.
  • Calculate Time: Enter distance and target pace. Useful for predicting your finish time for a specific race goal (e.g., a sub-4 hour marathon).
  • Calculate Distance: Enter time and pace. Useful for determining how far you ran during a timed workout.

Common Race Distances

  • 5K = 3.107 miles
  • 10K = 6.214 miles
  • Half Marathon = 13.109 miles (21.0975 km)
  • Marathon = 26.219 miles (42.195 km)
