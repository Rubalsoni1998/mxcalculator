About the Password Generator

A strong password is long, random and unique to each account. People are bad at creating randomness, so a generator produces better passwords than ones we invent.

This password generator creates random passwords in your browser, so nothing is sent to a server. Choose the length and character types you need.

How to Use the Password Generator

  1. Select the length of your password.
  2. Choose the character types: uppercase, lowercase, numbers and symbols.
  3. Click Generate and copy your password.

What Makes a Password Strong

Strength is measured in bits of entropy: entropy = length × log₂(pool size). A 12-character password from 94 symbols has about 79 bits; 16 characters gives about 105 bits.

Example: A random 16-character password using letters, numbers and symbols has roughly 105 bits of entropy, which would take far longer than any realistic attack.

Password Safety Tips

  • Use a different password for every account.
  • Store passwords in a password manager.
  • Turn on two-factor authentication.
  • Never share passwords by email or chat.

What This Generator Actually Uses

The page script builds a character pool from your checkboxes, then picks each character using window.crypto.getRandomValues, the browser's cryptographically secure random source. It does not use Math.random. Each pick takes a 32-bit random value and reduces it to the pool size. That introduces a bias too small to matter, because the pool has fewer than 100 characters while the random value has over four billion possible values.

Characters can repeat, as they would in any random password. The script contains no code that sends the result anywhere, but you are still responsible for where it goes after you copy it.

What the Strength Meter Measures

The colored bar is a simple points score. It adds points for length thresholds and for each character type present. It does not compute entropy and does not know whether a password has appeared in a breach. Treat it as a rough guide, and rely on length and randomness instead.

What NIST Guidance Says

NIST SP 800-63B, the US federal guidance on digital identity, moved away from old habits. Its main points:

  • Length matters more than complexity. Rules that force a mix of uppercase, digits and symbols are discouraged, since they push people toward predictable patterns like a capital first letter and a trailing "1!".
  • Do not force periodic password changes. Change a password when there is evidence it was compromised.
  • Services should check new passwords against lists of known breached or commonly used passwords.
  • Services should allow long passwords (at least 64 characters) and allow pasting, so password managers work.

Minimum lengths and some details differ between versions of the document, so read the current text for exact requirements. Many sites still impose their own rules. If a site demands a symbol or a maximum length, tick the matching boxes and shorten only as far as you must.

Putting It to Use

Generate a unique password for each account, paste it straight into a password manager, and turn on two-factor authentication wherever it is offered. Frequently Asked Questions

How long should a password be?

At least 12 characters; 16 or more for important accounts.

Is this generator safe?

Passwords are generated locally in your browser and are not stored.

Are symbols necessary?

Length matters most, but a larger character set adds strength.

What is a passphrase?

A password made from several random words, which is easy to remember and strong if long.

Is a browser-based password generator safe to use?

It can be, if it uses the browser's cryptographic random source and runs locally. This tool uses crypto.getRandomValues. Still, use a trusted device, avoid shared computers, and paste the result directly into a password manager.

How long should my password be?

Longer is better. For a randomly generated password stored in a manager, 16 or more characters is a sensible habit. For a master password you must remember, consider a long passphrase. Check each site's rules, since some cap length.

Do I need to change my passwords regularly?

NIST guidance advises against forced periodic changes. Change a password when you suspect it was exposed, when a service reports a breach, or when you shared it. Use a unique password per account so one breach does not spread.

Why does the generator exclude similar-looking characters?

Characters like l, 1, I, O and 0 are easy to confuse when you read or type a password by hand. Excluding them helps when you must copy a password manually, at a tiny cost in strength that extra length easily covers.
